# Better Badminton Vlaanderen

Companion app for the [Badminton Vlaanderen](https://www.badmintonvlaanderen.be) portal. It adds what the portal lacks, for players, clubs and administrators in Flanders. Available on web and mobile.

**Features** (planned, details in [DOCUMENTATION.md](DOCUMENTATION.md)):
- Ranking simulations, tournament predictions and competition "what-if" scenarios
- Tournament draws in a compact overview, with links to toernooi.nl
- Favorites dashboard: stats, graphs and history of your favorite players and teams
- Club management: versioned interclub team composition, solver-generated base teams, exports
- User accounts and login (later phase)

**Stack:** Spring Boot (hexagonal architecture), React + TypeScript, React Native (Expo), PostgreSQL.
